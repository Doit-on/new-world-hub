🏛️ 1. แหล่งที่มาของหลักสูตรและเนื้อหาบทเรียน (Curriculum Attribution)

• หลักสูตรแกนกลาง: จัดทำขึ้นโดยอิงตามตัวชี้วัดและสาระการเรียนรู้แกนกลาง กลุ่มสาระการเรียนรู้ภาษาต่างประเทศ (ภาษาอังกฤษ) ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พ.ศ. 2551 (ฉบับปรับปรุง พ.ศ. 2560) สำนักงานคณะกรรมการการศึกษาขั้นพื้นฐาน (สพฐ.) กระทรวงศึกษาธิการ

• ชุดหนังสือเรียนอ้างอิง: ถอดโครงสร้างเนื้อหา 72 บทเรียนจากหนังสือเรียน New World 1 - 6 (ระดับชั้น ม.1 - ม.6) โดย Manuel dos Santos จัดพิมพ์โดยสำนักพิมพ์ไทยวัฒนาพานิช (ทวพ.)

🎙️ 2. ระเบียบวิธีและมาตรฐานการวิเคราะห์เสียงพูด (Speech Recognition & Phonetic Evaluation)

• เทคโนโลยีการรับเสียง: ทำงานผ่าน W3C Web Speech Recognition API มาตรฐานระดับสากล แปลงคลื่นเสียงพูดภาษาอังกฤษสำเนียง en-US แบบเรียลไทม์

• อัลกอริทึมการคำนวณคะแนน: ระบบนำข้อความที่ถอดเสียงได้ (Speech Transcript) มาคำนวณระยะห่างทางอักขรวิธีกับประโยคเป้าหมาย (Target Sentence) ด้วยอัลกอริทึม Levenshtein Distance & Phonetic Token Alignment โดยคิดเป็นร้อยละความแม่นยำ (Pronunciation Accuracy Score: 0 - 100%):

Accuracy = max(0, 100 × (1 - LevenshteinDistance(Target, Recognized) / max(TargetLen, RecognizedLen)))

• เกณฑ์การวัดผล:

  • 85% - 100% (Excellent): การออกเสียงชัดเจน ใกล้เคียงเจ้าของภาษา
  • 70% - 84% (Good): การออกเสียงสื่อสารได้ชัดเจน มีจุดคลาดเคลื่อนเล็กน้อย
  • ต่ำกว่า 70% (Needs Practice): ควรฝึกซ้ำโดยกดฟังเสียงครูต้นแบบ

📊 3. มาตรฐานการวิเคราะห์ข้อสอบและการจำแนกทักษะ (Item Analysis & CTT Framework)

• ทฤษฎีการทดสอบ: อิงตาม Classical Test Theory (CTT) และ Bloom's Revised Taxonomy (Remembering, Understanding, Applying, Analyzing)

• แบบทดสอบ 5 ข้อมาตรฐานสากลต่อหน่วยการเรียนรู้:

  • 1. ไวยากรณ์และโครงสร้าง (Grammar & Structure): ข้อ 1 และ 2 (วัดความจำและความเข้าใจหลักไวยากรณ์)
  • 2. คำศัพท์ในบริบท (Vocabulary in Context): ข้อ 3 (วัดการนำคำศัพท์ไปประยุกต์ใช้ในประโยคจริง)
  • 3. บทสนทนาสถานการณ์ (Social & Situational English): ข้อ 4 (วัดความเหมาะสมในการสื่อสารตามบริบท)
  • 4. การอ่านจับใจความ (Reading Comprehension): ข้อ 5 (วัดความเข้าใจเนื้อหาบทอ่านจริงในบทเรียน New World)

🔒 4. นโยบายความปลอดภัยและความเป็นส่วนตัว (Privacy & Zero-Disk Storage Compliance)

• Client-Side In-Memory Only: ประมวลผลและเก็บข้อมูลเสียงในหน่วยความจำชั่วคราว (RAM / Blob URL) ของเบราว์เซอร์เท่านั้น

• Zero-Disk Storage: ไม่มีการบันทึกเสียงลงฮาร์ดดิสก์ของเครื่อง ไม่มีการส่งข้อมูลเสียงขึ้น Server หรือ Cloud ภายนอก

• Automatic Memory Cleanup: เมื่อผู้ใช้เปลี่ยนบทเรียน หรือปิดหน้าต่างเบราว์เซอร์ ข้อมูลเสียงจะถูกทำลายทิ้งทันทีตามหลักเกณฑ์ PDPA
